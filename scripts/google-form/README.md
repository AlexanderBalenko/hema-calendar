# Форма заявки на турнир

Сайт статический и принять запись не может, поэтому заявки собирает Google-форма, а раз в
сутки импорт превращает новые ответы в пул-реквест. Заявителю не нужен ни аккаунт GitHub, ни
git — только заполнить форму.

Форма создаётся **один раз** и **в вашем гугл-аккаунте**: чужой аккаунт я завести не могу, да
и не должен. Скрипт ниже делает всё остальное сам.

## Что получится

```
Форма «Календарь HEMA — заявка на турнир»
      │
      ├──→ «заявки (ответы)»      приватная таблица: ВСЕ поля, включая контакт заявителя
      │
      └──→ «заявки (для импорта)» открыта по ссылке: только то, что и так станет публичным
                                   (название, даты, место, организаторы, ссылка, номинации)
                                        │
                                        └──→ импорт календаря → пул-реквест → вы мёрджите
```

Таблицы две не для красоты: импорту нужна таблица, читаемая без входа в аккаунт, а контакт
заявителя в такой таблице стал бы публичным. Контакты остаются в приватной — там вы их и
смотрите, когда в заявке что-то неясно.

## Пять шагов

1. Откройте [script.google.com](https://script.google.com/home/projects/create) — создастся
   пустой проект Apps Script.
2. Замените содержимое `Код.gs` на файл `create-form.gs` из этой папки.
3. Сверху выберите функцию **`setup`** и нажмите **Выполнить**. Google спросит разрешения
   (формы, таблицы, диск) — это ваш же скрипт, разрешите.
4. Откройте **Журнал выполнения** (Ctrl+Enter) — там четыре строки, они и нужны:

   ```
   SUBMIT_FORM_URL = https://docs.google.com/forms/d/e/…/viewform
   FORM_SHEET_ID   = 1AbC…
   FORM_SHEET_GID  = 0
   ```

5. Пришлите их мне — или положите сами в репозиторий:
   **Settings → Secrets and variables → Actions → Variables**, три переменные с теми же
   именами (`SUBMIT_FORM_URL`, `FORM_SHEET_ID`, `FORM_SHEET_GID`).

После этого кнопка «Анонсировать турнир» на сайте начнёт вести в форму, а ночной импорт — приносить
заявки пул-реквестом.

## Проверить, что работает

Отправьте через форму пробную заявку и запустите импорт руками: **Actions → Импорт турниров →
Run workflow**. Через минуту появится пул-реквест с новым файлом в `data/events/`. Если заявка
пробная — просто закройте пул-реквест, в календарь ничего не попадёт.

## Чего не делать

- **Не переименовывайте вопросы формы.** Их названия — контракт с импортом
  (`scripts/import_spreadsheet.py` читает колонки `Название`, `Дата начала`, `Дата завершения`,
  `Город`, `Адрес`, `Организатор`, `Со-организаторы`, `Ссылка`, `Номинации`). Переименуете — заявки перестанут
  доезжать молча.
- **Не открывайте доступ к таблице ответов.** В ней контакты людей. Публичная — только вторая.
- **Не чистите публичную таблицу** от уже импортированных строк: импорт узнаёт свои записи по
  дате и названию и повторно их не заводит, а вот пустая таблица ничего не сломает — просто
  новых заявок в ней не будет.
